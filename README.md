## GitHub Pagesでの公開手順（新規リポジトリの場合）
1. GitHubで新しいリポジトリを作成する（例: `agml-vol2-kobe`）
2. このフォルダの中身一式をリポジトリ直下にアップロード（このREADME.mdも含めてOK）
3. リポジトリの Settings → Pages を開く
4. 「Source」を `Deploy from a branch` にし、Branch を `main` / フォルダを `/(root)` に設定して Save
5. 数分後、`https://（ユーザー名）.github.io/agml-vol2-kobe/` で公開されます
